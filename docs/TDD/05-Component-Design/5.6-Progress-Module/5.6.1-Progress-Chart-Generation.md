# 5.6.1 Progress Chart Generation

Progress Chart Generation is a background process that calculates and stores historical progress data for S-curve visualization. This enables project managers and stakeholders to track actual progress against planned baselines, identify trends, and forecast project completion.

## 5.6.1.1 Overview

The chart generation process runs automatically in the background whenever project progress data changes. It calculates historical progress snapshots and stores them for S-curve visualization. The process generates charts at multiple levels:

- **Per-SOW charts** - Individual SOW progress over time
- **Per-group charts** - Progress by item type (Linepipe, Bends, Flanges, etc.)
- **Overall chart** - Total project progress aggregating all groups

Each chart includes both monthly and daily data points for different visualization granularities.

## 5.6.1.2 Background Process

This is a background job that runs asynchronously without blocking user operations. The process is triggered automatically when:
- SOW is submitted or updated
- Work Order progress is updated
- Transfer data changes (tally recorded, status updated)

The job processes data in stages to handle large datasets efficiently and prevent performance issues.

## 5.6.1.3 Application Services

### 5.6.1.3.1 Calculate Progress Data

The ProgressChartService retrieves progress data from multiple sources and calculates progress percentages:

**Data Sources:**
- SOW records with planned quantities and delivery schedules
- Work Order records with manufactured, inspected, and shipped quantities
- Transfer records with cargo and tally data
- Project Control weights for progress calculation

**Progress Calculation:**
- Calculates progress percentage based on completed vs planned quantities
- Applies configured weight distributions from Project Control
- Aggregates progress across manufacturing, coating, inspection, and shipment stages
- Generates historical snapshots at monthly and daily intervals

**Caching:**
- Builds progress cache to avoid repeated database queries
- Cache contains pre-calculated progress stats for all SOWs and groups
- Significantly improves performance for large projects

### 5.6.1.3.2 Generate Per-SOW Charts

Generates individual progress charts for each submitted SOW:
- Creates monthly data points showing progress over time
- Creates daily data points for detailed tracking
- Stores chart data with SOW reference for retrieval
- Enables drill-down from overall progress to specific SOWs

### 5.6.1.3.3 Generate Per-Group Charts

Generates progress charts for each item type group (Linepipe, Bends, Flanges, etc.):
- Aggregates progress from all SOWs within the group
- Creates monthly and daily data points
- Enables comparison between different item types
- Supports filtering and analysis by group

### 5.6.1.3.4 Generate Overall Chart

Generates the overall project progress chart combining all groups:
- Aggregates progress from all item type groups
- Applies SOW weight percentages for accurate overall calculation
- Creates the main S-curve used in dashboards and reports
- Must be calculated last to ensure all group data is available

## 5.6.1.4 Performance Considerations

The chart generation process is optimized for large projects:

**Asynchronous Processing:**
- Runs in background without blocking user operations
- Prevents timeout issues for large datasets
- Allows users to continue working while charts generate

**Batch Processing:**
- SOWs are processed in batches to prevent memory issues
- Enables parallel processing for faster completion
- Configurable batch size based on project size

**Caching Strategy:**
- Progress calculations are cached to avoid N+1 query problems
- Cache is built once and reused across all chart generations
- Reduces database load significantly

**Duplicate Prevention:**
- Job locker prevents multiple simultaneous chart generations
- Ensures data consistency and prevents resource waste

## 5.6.1.5 Database

Chart data is stored in MongoDB:

**Project Database:**
• **progress_sow_chart** - Historical progress data:
  - `group` - Group name ('overall', 'linepipe', 'bends', 'flanges', or SOW ID)
  - `monthly` - Array of monthly data points with dates and progress percentages
  - `daily` - Array of daily data points for detailed tracking
  - `last_updated` - Timestamp of last generation

• **sow** - Source data for progress calculation
• **work_order** - Source data for completed quantities
• **transfer** - Source data for shipped quantities
• **project_control_sow_list** - Weight percentages for progress calculation
